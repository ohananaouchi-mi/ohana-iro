# オハナ色（ohana-iro）

Claude Code のデスクトップアプリ用のテーマ（mod）です。

- 昼：クリームの紙に、こげ茶の文字と朱色の差し色
- 夜：ランプに照らされた紙のような、こげ茶の画面
- 動く背景：雪がふり、電球がまたたき、窓の灯る小さな家
- 11月〜12月25日はクリスマス仕様（色とりどりの電球・ツリーの星・ドアのリース・空をとぶサンタさんのソリ）

## 入れ方

ターミナルの Claude Code で：

```
/plugin install ohana-iro --marketplace ohananaouchi-mi/ohana-iro
```

シェルから：

```
claude plugin install ohana-iro --marketplace ohananaouchi-mi/ohana-iro
```

デスクトップアプリで（`/plugin` が使えないとき）：入力欄の横の「+」→ Plugins → Add marketplace に `ohananaouchi-mi/ohana-iro` → Add plugin。
